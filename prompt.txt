2. SYSTEM ARCHITECTURE & STATE MANAGEMENT
-----------------------------------------
Since the original app is a "Local-First" SPA without a traditional backend, the 
Flutter app must replicate this simulated backend using local databases.
- State Management: Use Riverpod or Provider (similar to React Context/Custom Hooks) 
  to manage global states (auth, feed, profile).
- Local Database: 
  - Use `Hive` or `Isar` for persisting JSON-like objects (Users, Profiles, Posts).
  - Equivalents of `localStorage` keys to replicate: `svcet_users`, 
    `svcet_professional_profiles`, `svcet_activity_feed`, `svcet_faculty_skill_verifications`, 
    `svcet_communities`, `svcet_faculty_project_reviews`.
- Binary Attachments: Use `path_provider` and `sqflite` (or `Hive` binary support) 
  to replicate the original `IndexedDB` file storage for photos and document uploads.
- Routing: Use `go_router` for clean, role-based navigation and protected routes.

3. DATA ACCESS LAYER (The "Hooks")
----------------------------------
In React, custom hooks handle business logic. You must build equivalent Repositories 
or StateNotifiers in Flutter:
- ProfessionalProfileController: Manages retrieving user skills, projects, and the 
  global activity feed. Contains methods like `postActivity()`, `endorseSkill()`, 
  `likePost()`, and `addComment()`.
- SkillHubController: Manages XP, Gamification badges, Challenges, and Team formations.
- CommunityController: Manages domain-specific groups (Coding, AI, Design) and internal events.
- AuthController: Handles role-based login and session persistence.

4. CORE MODULES & FEATURES
--------------------------
The app has 3 distinct portals controlled by role-based access.

[A] ADMIN PORTAL
- Manage Users: Add, edit, or delete Faculty and Students.
- Academic Setup: Define Departments and Courses.
- Announcements: Push global notices.

[B] FACULTY PORTAL
- Academics: Manage Attendance, Grades, and upload Course Materials.
- Skill Verification: Faculty can view student profiles, verify their claimed skills, 
  and endorse them.
- Project Reviews: Faculty can browse student projects, rate them (1-5 stars), and leave feedback.
- Mentorship Hub: Faculty publish workshops/webinars directly into Student Communities.

[C] STUDENT PORTAL
- Dashboard: Overview of attendance, grades, and upcoming tasks.
- Practice & Coding Hub: Daily tasks with an interactive code execution environment UI.
- Achievements Module: A unified portfolio containing:
   * Overview: Profile strength, ranking, activity heatmap.
   * Activity Feed: Students can post updates with photo/document attachments, like, 
     comment, and share posts using the native share dialog (`share_plus` package).
   * Projects & Certificates: CRUD interface for academic accomplishments.
- SkillHub Ecosystem:
   * Communities: Domain groups with internal discussion feeds.
   * Challenges: Task completion for XP.
   * Team Finder: For hackathons and group projects.
